Run `python3 scripts/architecture/collect_phase1_baseline.py --check` in the pinned
checkout to reproduce. After baseline source changes, use a detached checkout of that
commit for historical reproduction and create a new audit revision for new findings.

The route inventory is a review worklist, not a live OpenAPI inventory or authentication
proof: router mounts/aliases, generated endpoints, MCP tools and some dynamically
registered paths are outside this AST collector. Prefixes are declared hints. Lack of a
tenant column does not mean no authentication; upstream intentionally protects many
operations with instance-level permissions. Source-reviewed access paths and their
actual gaps are in [the audit](../vigil-phase1-audit.md).
